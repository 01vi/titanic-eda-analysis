# Titanic EDA - Survival Analysis

## Overview
Exploratory Data Analysis on the Titanic dataset to uncover 
survival patterns based on gender, passenger class, and age.

## Key Findings
- Only 38% of passengers survived overall
- 74% of females survived vs only 19% of males
- 1st class passengers had 63% survival rate vs 24% in 3rd class
- Most passengers were between 20-30 years old

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
